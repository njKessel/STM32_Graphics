# STM32 Graphics
Inspired by some projects for running 3d game engines on things like the RP2040 and the ESP32, this projects goal is to make a 3d rasterized graphics engine on the STM32 F4, later to be ported to the more powerful STM32 H7. This is done fully bare-metal to practice my own work with C to better understand the hardware and to best optimize for rendering.
